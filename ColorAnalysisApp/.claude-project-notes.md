# Hue Garden — Project Notes

## Requirements Summary
- App name: "hue gardenu" (confirm exact casing/spelling)
- 12-season color analysis
- Onboarding quiz → results gated behind auth (sign up to unlock)
- Free tier first, paid tier if viral / hosting costs spike
- Live viewfinder with real-time color readout
  - Identify color name, rate 1-10, keep/forget callout
  - Also accepts static photo input
- Results sharing: profile PNG card + gift recommendation links by season
- Option to use viewfinder for shopping for a friend (select their season)
- Quiz retake: save history, show change in season if applicable
- Backend: Firebase (Auth + Firestore + Storage + Analytics)
- Claude API: user has a model trained on color palette data
- Offline mode: AsyncStorage cache
- iOS first
- Launch target: April 2026
- Design style: qoves.com — editorial, clean, serif, cream/white, sophisticated

## Architecture Decisions
- Expo SDK 53, managed workflow
- Firebase for auth/db/storage/analytics
- expo-camera for live viewfinder (periodic capture at low quality for "live" feel)
- Claude claude-opus-4-6 (or custom fine-tuned model) for deep color analysis
- pako for PNG pixel extraction (pure JS, no native module)
- react-native-view-shot for shareable profile PNG
- expo-sharing for share sheet
- AsyncStorage for offline caching
- PP Editorial New font (user has license on Desktop) for editorial aesthetic
